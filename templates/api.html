Read endpoints

JSON
Endpoint Returns
GET/api/catalogue Canonical item names, their aliases and pack sizes
GET/api/donations Every surplus listing with quantity, unit, expiry and status
GET/api/requests Open and fulfilled requests with urgency
GET/api/matches Proposed, accepted and completed matches with scores
GET/api/requests/<id>/candidates The five best-scoring donations for one request

Matching endpoints

signed in
Endpoint Does
POST/api/run-matching Runs a matching pass over the signed-in facility's own stock. Needs the session cookie and an X-CSRF-Token header.
GET/api/cron/maintenance Flags expired stock and runs the network-wide pass. Called by Vercel Cron with a bearer secret, not by browsers.

Writes are refused without a facility session, so these two return 401 or 403 to anything else. Browser forms carry a CSRF token; the cron route carries Authorization: Bearer <CRON_SECRET>.
